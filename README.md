# AI Code Scheduler - ONEJRA

**Software for structured development with local AI support.**

AI Code Scheduler helps organize the software development process into structured stages. Integration with local AI supports planning and carrying out subsequent steps while maintaining a simple project structure.

## Features

- Organize software development workflows.
- Divide the development process into structured stages.
- Plan subsequent development steps.
- Maintain a clear and organized project structure.
- Optional local AI support for planning and development.
